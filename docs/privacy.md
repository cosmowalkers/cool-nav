# Cool Nav 隐私政策

最后更新：2026-09-29 · 适用版本：0.1.x

> 这份文档要作为 Chrome / Edge 应用商店的「隐私政策 URL」对外可访问，所以放在仓库里（而不是内部知识库）。

## 一句话

Cool Nav 是一个纯本地的新标签页扩展：**不收集、不上传你的任何数据**，没有账号体系，没有服务端，也没有统计与埋点。

## 我们不做什么

- 不收集个人信息、浏览记录、搜索词或链接内容
- 不向任何自建服务器发送数据（本扩展没有自建服务器）
- 不投放广告，不使用第三方统计 / 分析 / 崩溃上报 SDK
- 不读取或修改你访问的网页内容，除非你主动点「允许读取标题」并只为该域名授权（见下）
- **不申请、也不使用系统的定位权限**：位置只按出口 IP 推断，城市级精度，且可以随时手填覆盖
- 不把数据卖给或共享给第三方

## 数据存在哪里

全部数据都存在你自己的浏览器里，只有你自己能读到：

| 存在哪 | 存了什么 | 说明 |
| --- | --- | --- |
| `chrome.storage.sync` | 你添加的链接与分组、设置（默认引擎、亮暗色、背景来源、天气城市、开关项） | 开启浏览器账号同步时，这部分会随着你的浏览器账号同步到你的其他设备。同步由浏览器厂商提供，开发者无法访问 |
| `chrome.storage.local` | 每日一图缓存（只是一批图片地址和日期）、当前背景地址、天气与调休日历缓存、按 IP 推断出的城市坐标 | 只在本机，不参与同步，也不出现在导出的备份里 |
| 浏览器搜索历史 | 最近 30 条搜索词 | 仅在你开启「记录搜索历史」时写入，可随时在设置里清除；它只存在浏览器本地存储里 |

图片本身不会被保存：背景图片只记录地址。你可以随时在编辑态导出 JSON 备份，或卸载扩展清空全部数据。

## 这个扩展会发出哪些网络请求

只有下面这几个，全部由你的浏览器直接发起，请求里不包含任何用户标识、账号或设备 ID：

| 目标 | 用途 | 何时请求 | 发出什么 |
| --- | --- | --- | --- |
| `www.bing.com` | 取 Bing 每日一图作为背景 | **只有你允许之后才会请求**（每天首次打开新标签页，或你手动换图） | 只有一个地区参数的公开接口请求；图片本身按地址加载 |
| `api.open-meteo.com` | 天气 | 打开新标签页且天气缓存超过 30 分钟 | 纬度、经度（来自 IP 推断，或你手填城市的解析结果） |
| `geocoding-api.open-meteo.com` | 把你填的城市名转成经纬度 | 你手动设置城市时 | 城市名 |
| `api.bigdatacloud.net` | 按你的出口 IP 反查城市名（唯一的位置来源） | 打开新标签页且天气缓存超过 30 分钟，或你改了城市 | **不发送任何坐标**：这是它按连接来源 IP 判断的无参接口 |
| `fastly.jsdelivr.net` 等 CDN | 取当年的法定节假日 / 调休日历（[holiday-cn](https://github.com/NateScarlet/holiday-cn)） | 打开新标签页且缓存超过 7 天 | 只请求一个按年份命名的公开 JSON 文件 |
| 你添加的网址 | 在你点「允许读取」后读取该网页标题，用于自动填写链接名称 | 只在添加链接时，且仅针对你授权的那一个域名 | 一次普通的网页请求（不带 cookie） |

除上述请求外，扩展不会主动联网。上述第三方服务会按它们自己的隐私政策处理请求（含常规的 IP 地址、User-Agent）；
它们的处理方式不由本扩展控制。相关隐私政策：
[Bing](https://privacy.microsoft.com/privacystatement)、
[Open-Meteo](https://open-meteo.com/en/terms)、
[BigDataCloud](https://www.bigdatacloud.com/privacy-and-cookie-policy)、
[jsDelivr](https://www.jsdelivr.com/privacy-policy-jsdelivr-net)。

## 权限与用途

| 权限 | 用途 | 是否必需 |
| --- | --- | --- |
| `storage` | 保存你的链接与设置 | 必需 |
| `favicon` | 用浏览器内置接口取站点图标（`_favicon`），不访问任何第三方图标服务 | 必需 |
| `https://www.bing.com/*` | 获取每日一图列表，作为背景 | **可选、用到时才申请**：不授权也能正常用，背景会退回纯色底 |
| 其他网站（`http://*/*`、`https://*/*`） | 只用于「抓网页标题自动命名」 | **可选、按域名申请**：不授权也能正常用，只是添加链接时名称回退成域名 |

扩展不声明任何「读取所有网站数据」这类必装主机权限：上面两项都是可选的，装的时候不会出现全量权限提示。
每日一图只申请 `bing.com` 一个域名；抓标题的授权只针对你当时添加的那一个域名。两者都可以随时在浏览器扩展详情页里撤销，撤销后对应功能自动退回纯色底 / 域名命名。

## 数据删除

- 卸载扩展：浏览器会清空本扩展的全部本地与同步数据
- 只想清空内容：在编辑态导入一份空白 JSON，或使用浏览器提供的扩展数据清理入口
- 只清搜索历史：设置面板 → 搜索 → 清除搜索历史

## 儿童隐私

本扩展不面向儿童，也不收集任何年龄段信息。

## 变更

本政策的变更会随扩展版本一起发布，并在本文件顶部更新日期；涉及新的数据用途时会同时在扩展更新说明里写明。
