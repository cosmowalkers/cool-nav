# Cool Nav

极简新标签页，Chromium/Edge 扩展（Manifest V3）。纯本地、无后端，不收集任何数据。

## 功能

- **命令面板**：搜索框宽 760px，聚焦即展开；输入时结果分「链接 / 命令 / 历史 / 搜索」四块——
  链接按标题或 URL 模糊匹配直达（**命中按打开频率 + 最近使用重排**），命令可执行常用操作，
  历史是本地搜索记录，兜底交给默认引擎搜索；空输入时先列「最近打开」，再列命令。
  默认 Bing，可切换 Google / GitHub；前缀直达（`gg` / `gh`）；输入像网址直接跳转。
- **分组快捷方式**：中栏直接铺在页面底色上，按分组标题 + 无边框文本行排布，一行 5~6 条。
  每条只放「18px 图标 + 站点名」，不写描述；图标依次尝试：你自己填的图标 → 浏览器缓存的 favicon →
  站点自己的 `/favicon.ico` → 首字母色块（颜色由域名决定，同站恒定）。
  浏览器缓存里没有（也就是你还没在这个浏览器里打开过那个站）才会走第三步，所以看不到 logo 通常不是网速问题；
  还有一部分站点把图标放在 `/logo.svg` 这种非根目录位置，猜不到——命令面板里有「**补全图标**」：
  一次授权后逐个访问这些站点、读页面里自己声明的图标并写进链接，之后就不再依赖浏览器缓存。
- **背景**：纯色为默认（就是页面底色），也可以填一个自己的图片地址铺在顶部那条。**扩展本身不带任何图片资源**
- **亮暗色**：右上角一键切；设置里还能选「跟随系统 / 浅色 / 深色」。深色复刻 Ghostty 的 **Chester**
  （`#2c3643` 底 / 青 `#27dede` 强调），浅色复刻 **Atom One Light**（`#f9f9f9` 底 / 蓝 `#2f5af3` 强调）。
  两套色板写在同一个 `light-dark()` 里，靠 `color-scheme` 切换，不存在两份色值对不上的问题
- **编辑态**：按 `E` 或点右上角那支铅笔（一直显示）进入，可增删改链接、拖拽排序、新建分组；
  编辑态里删除按钮常显，每组格栅最后一块是「添加」。删链接不弹确认框，改成底部 6 秒撤销条
- **键盘导航**：`←→↑↓` 按屏幕位置在链接间移动，`Enter` 打开；`1~9`（焦点在链接区）/ `Alt+1~9`（全局）
  直达第 N 组，`Home` / `End` 跳首尾，按 `?` 随时调出快捷键帮助。编辑态里 `Delete` 删、`N` 新建、
  `⌘/Ctrl+←→` 排序，全程不用碰鼠标
- **右侧信息栏**：时间 / 日期 / 农历（含干支生肖）+ 节日 + 天气（当前温度与今日高低）；
  今天休不休息、是否补班和下一个假期，并进日期下面那一行小字；下面还带一组小工具：
  翻译（中英互译，走 MyMemory 免费接口）、
  二维码（本地生成）
- **念念不忘，必有回响**：按 `M`（或命令面板「记一条念念不忘」）随时弹出浮层记录灵感，Enter 保存、Shift+Enter 换行；
  存在 `storage.local`，右侧信息栏有最近几条预览和「记一条」入口，可回顾 / 删除
- **天气位置**：**不申请定位权限**，位置只按出口 IP 推断，不支持手填城市；
  IP 反查会尽量给到区/县（如 天津 · 西青区）。卡片上有刷新按钮，随时重新拉取
- **数据**：`chrome.storage.sync`，跟随浏览器账号跨电脑同步；图标只存 URL，不落库；
  别的标签页或设备改了数据，这边会跟着变（本地有待写入的改动时不抢）
- **备份**：命令面板可导出 / 导入 JSON

## 开发

```bash
npm install
npm run dev      # 普通网页里预览：无扩展 API，图标走色块兜底，数据存 localStorage
npm run build    # 产物在 dist/，同时就是一个可直接加载的扩展目录
```

## 装到 Edge

1. `npm run build`
2. 打开 `edge://extensions`，打开「开发人员模式」
3. 点「加载解压缩的扩展」，选择 `dist/` 目录
4. 新标签页就是它了

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `/` 或 `Cmd/Ctrl + K` | 聚焦搜索框 |
| `?` | 打开 / 关闭快捷键帮助 |
| `↑` `↓` | 搜索框展开时，在命令面板的结果间移动 |
| `↓` | 搜索框空输入时，直接进入链接区 |
| `Enter` | 执行选中的结果；没选中时按默认引擎搜索 |
| `Cmd/Ctrl + Enter` | 在命令面板里用新标签页打开（和浏览态 `Cmd/Ctrl + 点击` 同一个语义） |
| `←` `→` `↑` `↓` | 焦点在链接上时，按屏幕位置在链接间移动 |
| `1~9` | 焦点在链接上时，跳到第 N 个分组的第一条（`Alt+1~9` 全局可用） |
| `⌘/Ctrl + ↑ ↓` | 跳到第一 / 最后一个链接 |
| `Delete` / `Backspace` | 编辑态删除当前链接（底部 6 秒可撤销） |
| `N` | 编辑态在当前分组末尾新建链接 |
| `⌘/Ctrl + ← →` | 编辑态在当前分组内移动排序 |
| `E` | 切换编辑模式 |
| `Esc` | 关弹窗 / 退编辑 / 从链接回到搜索框 / 收起命令面板 |

## 数据与配额

`chrome.storage.sync` 的限额是总量 100KB、单条 8KB。链接只存标题和 URL，图标不写进存储，
所以几十到几百条都不会碰到上限。真超了页面底部会给出提示，先导出备份再精简。
写入内容没变时不会重复写；撞上「写得太频繁」这类限流会自动重试，不会把这几分钟的编辑丢掉。
如果同步里的数据读不出来（比如跨设备写坏了），页面回退到预置链接并且**不覆盖**原数据。
数据结构换过两轮，读进来都认：`version: 1` 的旧分组直接沿用（只补写版本号），`version: 2` 那份铺平的
链接列表会被包进一个「常用」分组，读到时顺手落盘成新结构。

天气、地理编码、调休日历（天气 30 分钟、调休 7 天）和每个链接的打开次数缓存在 `storage.local`，
不参与同步也不进导出；打开次数的账本只留最近用过的 200 条，只用来给命令面板排序。

## 设计

完整的决策记录、数据模型和踩坑在 [docs/design.md](docs/design.md)，下面是速览。

- **版式**：顶部纯色带搜索框（高 `clamp(96px, 15vh, 128px)`，搜索框 760px），下面两栏——
  自适应中栏 + 270px 信息栏（`xl` 起出右栏）；容器 `max-w-1400`
- **字号**：正文 14px、分组标题 18px / 600、站点名 14px / 500、次要信息 12px
- **背景**：纯色为默认，可选自定义图片铺在顶部那条；图片无动效，不用蒙版
- **图标**：`C + 出走的箭头`。16px 单独用简化版（只留 C，工具栏那一档才不会糊成蓝点），48 / 128 用完整图形；
  6 套备选留在 `docs/logo-options.html`
- **动效**：入场 140ms 淡入，卡片 hover 0.15s，`prefers-reduced-motion` 下全部关闭

## 已知边界

- **没有任何全量 host 权限**：装的时候不会出现「读取所有网站数据」。抓标题和补图标这两处用网的能力
  都是按需申请，只在用到的那一刻问一次；不给就分别退回「域名命名」和「继续靠浏览器缓存」。
  `npm run dev` 的网页环境跨域拿不到标题，抓标题也会回退成域名
- 天气和调休依赖外部接口：天气走 Open-Meteo（只发经纬度）、反查地名走 BigDataCloud、
  调休走 [holiday-cn](https://github.com/NateScarlet/holiday-cn)（按国务院通知手工维护）。取不到时天气那一格
  显示原因、可点刷新重试，调休退回「周末＝休息」的规则，页面其余部分不受影响；
  农历由浏览器内置历法算，不联网
- 位置是**按出口 IP 推断**的：出差、挂代理、公司出口在别的城市时会推错（不支持手填，只能点刷新重试）。
  之所以不用浏览器定位，是因为 Chromium 在系统定位不可用时会退回
  Google 的定位服务，这个服务在国内不可达，即使把系统权限全开也只会拿到「设备定位不可用」——
  不如省掉这个权限和这套不确定性
- 不支持手机端：手机浏览器装不了自制扩展，这是当初主动砍掉的范围
- 没有回收站：删链接靠底部那条 6 秒撤销条后悔（过了就真没了），删分组仍然二次确认。兜底手段是导出 JSON
- `docs/seed-links.json` 是官方预置之外的备选链接池（35 条公开站点），不参与构建，不需要可直接删
