# Cool Nav

自用的极简新标签页，Chromium/Edge 扩展（Manifest V3），纯本地、无后端。

## 功能

- **搜索框**：默认 Bing，可切换引擎；前缀直达（`gg` / `bd` / `bz` / `gh` / `npm`）；输入像网址直接跳转；本地搜索历史
- **快捷方式**：不分组的铺平网格，从搜索框下面往下铺；图标走浏览器原生 favicon，取不到时落首字母色块（颜色由域名决定，同站恒定）
- **背景**：三种来源——内置渐变（极光 / 晨曦 / 墨蓝，零图片资源）、Bing 每日一图、本机图库；支持轮换节奏（每次新开 / 每小时 / 每天 / 不切换），切换带 900ms 交叉淡入
- **可读性**：图片内容不可控，所以有背景时自动锁深色文字体系 + 可调蒙版（弱 / 中 / 强）
- **编辑态**：按 `E` 或点右上角铅笔进入，可增删改链接、拖拽排序
- **键盘导航**：`Tab` 按顺序走，`←→↑↓` 按屏幕位置在瓦片间移动，`Enter` 打开；焦点环走强调色
- **数据**：`chrome.storage.sync`，跟随浏览器账号跨电脑同步；图标只存 URL，不落库；
  别的标签页或设备改了数据，这边会跟着变（本地有待写入的改动时不抢）
- **备份**：编辑态可导出 / 导入 JSON

## 开发

```bash
npm install
npm run dev      # 普通网页里预览：无扩展 API，图标走色块兜底，数据存 localStorage
npm run build    # 产物在 dist/，同时就是一个可直接加载的扩展目录
```

## 装到 Edge

1. `npm run build`
2. 打开 `edge://extensions`，打开「开发人员模式」
3. 点「加载解压缩的扩展」，选择 `dist/` 目录
4. 新标签页就是它了

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `/` 或 `Cmd/Ctrl + K` | 聚焦搜索框 |
| `↓` | 搜索框里按：直接进第一块瓦片（有历史联想时则是选历史） |
| `←` `→` `↑` `↓` | 焦点在链接上时，按屏幕位置在瓦片间移动 |
| `Enter` | 打开聚焦的链接 |
| `E` | 切换编辑模式 |
| `Esc` | 关弹窗 / 退出编辑 / 从瓦片回到搜索框 / 清空搜索框 |

## 数据与配额

`chrome.storage.sync` 的限额是总量 100KB、单条 8KB。链接只存标题和 URL，图标不写进存储，
所以几十到几百条都不会碰到上限。真超了页面底部会给出提示，先导出备份再精简。
写入内容没变时不会重复写；撞上「写得太频繁」这类限流会自动重试，不会把这几分钟的编辑丢掉。
如果同步里的数据读不出来（比如跨设备写坏了），页面回退到预置链接并且**不覆盖**原数据。
从分组版（`version: 1`）升级上来时，旧数据会按分组原顺序铺平成一条列表，并自动落盘成新结构。

本机图库和每日一图的缓存都存在 `chrome.storage.local`（图片写入前统一缩到 2400px、转 WebP），
不参与同步、也不会出现在导出的 JSON 里，换台电脑需要重新收集。
每日一图是公开接口，一天只请求一次，取不到就继续用缓存里的那批。

## 设计

完整的决策记录、数据模型和踩坑在 [docs/design.md](docs/design.md)，下面是速览。

- **版式**：时钟和搜索框顶部锚定（离顶 `clamp(64px, 13vh, 140px)`），链接从下面往下铺——加链接只往下长，头部不会跟着漂；时间 76px 细字重
- **壁纸三层**：渐变或图片层 → 蒙版层 → 颗粒层（内联 SVG 噪点，零资源）；图片层用 `<Transition>` 做交叉淡入，叠加 52s 极慢推近
- **动效**：入场错峰上浮 620ms，`prefers-reduced-motion` 下全部关闭
- **踩过的坑**：入场动画的 `animation-fill-mode` 只能用 `backwards`。用 `both` 会让 `transform` 一直挂在元素上，
  该元素就成了层叠上下文，下拉面板的 `z-index` 会被困在里面，站点图标会压到面板上面

## 已知边界

- 「抓网页标题自动命名」依赖扩展的 host 权限；`npm run dev` 的网页环境会失败并回退成域名
- 不支持手机端：手机浏览器装不了自制扩展，这是当初主动砍掉的范围
- 没有回收站，删除不可撤销，兜底手段是导出 JSON
- `docs/seed-links.json` 是早期从浏览器收藏夹里整理出来的备选链接，不参与构建，不需要可直接删
